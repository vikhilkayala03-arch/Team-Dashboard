## Research

The dashboard design was inspired by common modern UI patterns such as:

- Dashboard navigation
- Card-based application layouts
- Sidebar navigation
- Responsive grids
- Search and filtering interfaces
- Clear visual hierarchy

The implementation is an original design created for this project and does not copy any existing website.

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open `index.html`.
4. Run using Live Server or another local web server.
5. Navigate through Vikhil Apps, Akhil Apps and Ramsai Apps.
