# SkinMix artwork

Created with the built-in image-generation tool. Both outputs were visually inspected and copied into this project. No external image requests are needed when the app runs.

- `assets/skincare-hero.png`: Premium photoreal skincare still life, ivory/beige stone plinths, amber serum dropper, blush tube, cream moisturizer jar, subtle botanical sprig, cream background, warm soft daylight, left negative space. No promotional text, interface or logos.
- `assets/product-atlas.png`: Square contact sheet, exactly three columns and three rows. Nine generic sample packages centered in equal cells with pastel backgrounds and soft shadows: white pump cleanser, amber serum, green moisturizer; peach sunscreen, lavender toner, pink cleanser; green serum, lilac cream, beige lip balm. No grid lines or real brand logos. Product cards use CSS background positions to display individual cells.
- `assets/favicon.svg`: Simple SkinMix-colored droplet favicon, created as vector interface branding.

The generic mock packages intentionally do not claim to depict the named brands’ real products. The demo discloses this globally and on product pages.
